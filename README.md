# 生態世界 v0.4 — 可安裝／離線 PWA

這是 v0.3「平面方塊生態世界」的 **離線安裝升級版**。原有地形、生態區、動植物及操作方式維持不變，新增 PWA 安裝、資源快取、更新管理，並降低觸控設備 3D 內部繪製解析度以減輕 GPU 負擔。

## 上傳 GitHub Pages

1. **先刪除舊版根目錄不再需要的檔案（可留但非必要）**，再將這個資料夾中 `index.html`、`sw.js`、`manifest.webmanifest`、`js/`、`styles/`、`vendor/`、`icons/` 全部上傳到相同儲存庫的根目錄；務必保留目錄層級。
2. GitHub Pages 設定使用該儲存庫的 `main` 分支根目錄。
3. 用 HTTPS 的 GitHub Pages 網址開啟一次；等頁面正常顯示，按右上角「📲」確認 **已快取 12 個資源**。
4. 每台設備都需在有網路時完成一次載入與快取，再把 Wi-Fi 關閉，從主畫面圖示測試離線開啟。

### iPad 安裝

使用 Safari 開啟 GitHub Pages 網站 → 分享 → 加入主畫面 → 若有「作為網頁 App 開啟」請開啟 → 加入。再從主畫面 App 圖示開啟測試。**不是下載 ZIP 到 iPad 並雙擊 HTML**。

### Windows／Mac 安裝

使用 Chrome 或 Edge 開啟網頁 → 網址列的安裝圖示，或選單的「安裝此網站為應用程式」。使用應用程式捷徑開啟。部分瀏覽器的安裝選項名稱不同。

## 離線原理與注意事項

- 目前只需一次下載這個版本的 3D 引擎與網站資源；日後正常離線開啟不需重新下載完整網站。**每台 iPad 都需單獨下載一次**；PWA 不能把一台設備的快取直接複製到 30 台設備。
- 大型 3D 函式庫 `vendor/three.min.js` 獨立放在共用快取。日後只更新生態資料／程式時，不必重複下載相同版本的 Three.js。
- Service Worker 的新版本會等全部必要檔案下載成功才可啟用；已開啟的課堂不會自動刷新頁面。可在右上角「📲」手動檢查／套用。
- 安裝成 App 是 PWA，不是 iOS 原生安裝包。離線資料由瀏覽器／作業系統管理；裝置儲存空間不足或清除網站資料時，快取可能被移除，因此上課前務必進行飛航／關 Wi-Fi 測試。
- 首次安裝或首次更新仍需 Wi-Fi；安裝不會減少裝置執行 WebGL 的記憶體消耗，因此仍須進行 iPad 實測。GitHub Pages 必須啟用 HTTPS。使用 `file://` 直接開啟 HTML 不具備 PWA 離線功能。

## 技術分層

- `index.html`：精簡入口與載入錯誤顯示
- `styles/app.css`：介面與 PWA 安裝視窗
- `vendor/three.min.js`：Three.js r149（MIT 授權；授權檔一起附上）
- `js/world-data.js`：12 種生態區與物種資料
- `js/world-engine.js`：地形／海洋／動植物 3D 程式
- `js/main.js`：使用者操作、鏡頭與地圖
- `js/pwa.js`：安裝、快取狀態、手動更新
- `sw.js`：服務工作者，本機離線快取
- `manifest.webmanifest` + `icons/`：安裝後的名稱及圖示

**範圍限制**：v0.4 不更動地理配置、教材內容或生物動畫。這版重點是安裝與離線體驗；沒有聲稱 iPad 已驗收。
