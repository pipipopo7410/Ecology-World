# 生態世界｜方塊大陸 v0.1

第一階段 **3D 世界基底**。本版專注世界模型，**沒有題目、任務、計分、食物鏈或族群消長**。

## 操作

- 電腦：WASD／方向鍵移動；拖曳旋轉視角；滾輪或 ＋－ 縮放；點地面自動走過去；點動物看名稱。
- iPad：點地面前往；單指拖曳旋轉；雙指縮放；點生物看名稱。
- 右上「生態區」快速前往 12 種環境；右下世界地圖也可直接點選傳送。
- 水域採「考察視角」：角色可在海面上移動，以便直接探索河口、珊瑚礁與海洋。生物模型及比例屬初步示意。

## 已建置

- 12 個相連的生態區域：凍原、針葉林、落葉闊葉林、常綠闊葉林、草原、沙漠、河流、湖泊、河口溼地、潮間帶、珊瑚礁、外海
- 有高低落差的方塊地形、河流連接湖泊與海岸、透明水面、樹木、植被、珊瑚
- 24 種示意物種資料與簡化模型（模型不是精確物種形態）
- 基本角色移動、鏡頭旋轉與縮放、地區選單、互動世界縮圖、生物名稱卡
- 預留資料分層：地形引擎與物種資料分離，可逐步擴充觀察放大、行為、族群消長、能量流動、物質循環

## GitHub Pages 部署

1. 在 GitHub 建立公開 repository，例如 `Ecology-World`。
2. **將本資料夾內全部內容放到 repository 根目錄**：`index.html`、`style.css`、`js/`、`vendor/`，不要少放任何檔案。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save。
4. 網址格式通常是 `https://帳號.github.io/Ecology-World/`。
5. 請在電腦與 iPad 上檢查：各個生態區能否切換、地形是否有高度差、生物是否可點選、移動與縮放是否正常。

## 架構

- `js/world-data.js`：**資料**，生態區顏色、範圍代表位置、示意物種。未來新增生物從這裡入手。
- `js/world-engine.js`：**世界**，生成地形、植被、水面與模型。
- `js/main.js`：**操控**，角色、鏡頭、選單、地圖與點擊互動。
- `vendor/three.min.js`：Three.js r149（MIT）。程式完整放在本站，無須 CDN，避免學校網路限制。

## 重要限制與下一階段

- 目前世界是**科學概念的示意地圖**，不是全球精確地理模型；生態系交界、物種和縮尺都要逐步校準。
- 地形與生物模型只求可辨認和低硬體負擔；人物可在水面移動是刻意的原型簡化，不代表真實生態。
- 後續應優先完成：穩定性與 iPad 交互測試 → 地形接縫與各生態區可辨認度 → 物種模型品質 → 生物資料規範。**暫不增加教學功能。**
